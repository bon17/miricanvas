# 수업 슬라이드 엔진: 기능 점검표

엔진이 갖춰야 할 기능과, 기능마다 "됐다"고 말할 기준을 적은 문서다. 원칙은 [CLAUDE.md](../CLAUDE.md)에 있다.

- `[ ]` 칸은 점검할 때 채운다. 실제로 눌러 본 것만 `[x]`로 표시한다.
- **(손)** 표시는 화면 없는 브라우저로 확인할 수 없어서 실제 기기에서 확인해야 하는 항목이다. 보고할 때는 "확인 못 함"에 넣는다.
- 단축키는 엔진을 만들 때 정하고, 정한 뒤 8장 표에 적는다.

---

## 0. 기본 조건

- [ ] HTML 파일 하나다. 더블클릭(`file://`)으로 열린다.
- [ ] 네트워크를 막은 상태에서도 모든 기능이 돌아가고 콘솔 오류가 0개다.
- [ ] 외부 스크립트(`<script src="http…">`)가 0개다. 외부에서 받는 것은 웹 폰트뿐이고, 되도록 파일 안에 넣는다.
- [ ] 1920×1080 무대가 비율을 지킨 채 확대·축소된다. 1280×720, 1920×1080, 2560×1440, 세로 화면에서 확인한다.
- [ ] 엔진과 디자인이 나뉘어 있다. 디자인이 다른 덱 두 개를 같은 엔진 파일로 빌드해서 둘 다 동작한다.
- [ ] 슬라이드 내용은 HTML이고, 모션은 data- 속성으로만 선언되어 있다. 덱 파일에 스크립트가 없다.

## 1. 이동

- [ ] 이전/다음: 남은 단계가 있으면 단계부터 진행한다. 뒤로 가서 들어온 슬라이드는 모든 단계가 펼쳐져 있다.
- [ ] 처음 / 끝으로 이동한다.
- [ ] 번호로 이동한다(숫자 + Enter, 그리고 입력칸).
- [ ] 목차: `data-title` 목록에서 눌러 이동한다.
- [ ] 슬라이드 썸네일 목록: 작게 줄인 실제 슬라이드 모습이다. 현재 위치와 숨긴 슬라이드가 표시된다.
- [ ] 클릭으로 넘긴다. 버튼·활동 요소를 누를 때는 넘어가지 않는다.
- [ ] 스와이프로 넘긴다. (손) 실제 터치로 확인한다.
- [ ] 주소 `#5`로 그 슬라이드에서 시작한다. 이동하면 주소도 바뀐다. 새로고침해도 위치가 유지된다.
- [ ] 숨긴 슬라이드(`data-hidden`)는 발표할 때 건너뛴다. 목차·썸네일에는 흐리게 보인다.
- [ ] 진행 표시가 있다(전체 중 어디쯤인지, 남은 단계).
- [ ] 페이지 번호가 있다. 전체 화면에서도 보인다.

## 2. 필기

- [ ] 펜: 필압이 굵기에 반영된다. (손) 실제 펜으로 확인한다. 필압이 없는 마우스에서는 속도로 굵기를 흉내 낸다.
- [ ] 형광펜: 반투명하고, 글자를 가리지 않는다.
- [ ] 지우개: 획 지우개와 부분 지우개가 있고, 크기는 3단계다.
- [ ] 레이저 포인터: 따라오는 점이 있고 잠시 뒤 사라진다. 기록은 남지 않는다.
- [ ] 색 6개, 굵기 3단계가 있다.
- [ ] 되돌리기 / 다시 하기가 된다(지우기도 되돌릴 수 있다).
- [ ] 이 장 지우기가 된다.
- [ ] 전체 지우기는 확인 창을 띄운 뒤 지운다.
- [ ] 필기는 슬라이드마다 저장된다. 다른 장에 갔다 오거나 새로고침해도 남아 있다.
- [ ] 창 크기가 바뀌어도 필기 위치가 슬라이드 내용과 그대로 맞는다(무대 좌표로 저장).

## 3. 발표 도구

- [ ] 칠판 모드: 여러 장을 추가·이동할 수 있다. 칠판에도 필기 기능을 모두 쓸 수 있고, 칠판의 필기도 저장된다.
- [ ] 타이머: 경과 시간과 카운트다운이 있다. 끝나면 알림(소리는 켰을 때만)이 나온다. 슬라이드를 가리지 않는 크기다.
- [ ] 축하 효과(색종이)가 나온다. 모션 "끄기"에서는 약하게 나오거나 나오지 않는다.
- [ ] 랜덤 뽑기: 번호 범위나 이름 목록에서 뽑는다. 이미 뽑은 것을 뺄 수 있다.
- [ ] 화면 가리기: 검은 화면 / 흰 화면이 된다. 아무 키나 누르면 돌아온다.
- [ ] 효과음은 타이머와 뽑기에만 나고 끌 수 있다. Web Audio로 만들어 인터넷 없이 난다. (손) 실제로 들어 본다.
- [ ] 발표자 보기: 새 창에 현재·다음 슬라이드, 노트(`<aside data-notes>`), 타이머가 보이고 본 창과 같이 움직인다. `file://`에서도 이어지는지 확인한다(예: 열어 준 창끼리 `postMessage`).

## 4. 전체 화면

- [ ] 전체 화면에서는 슬라이드와 페이지 번호만 보인다.
- [ ] 화면 가장자리에 마우스를 대거나 탭하면 도구가 잠깐 나타났다가 다시 숨는다.
- [ ] 마우스가 멈추면 2초쯤 뒤 커서가 숨는다.
- [ ] (손) 실제 전체 화면(F11, 버튼)으로 확인한다. 화면 없는 브라우저에서는 흉내만 낼 수 있다.

## 5. 편집 모드

**요소 다루기**
- [ ] 모든 요소를 선택하고, 옮기고, 크기를 바꾸고, 돌릴 수 있다. 여러 개 선택(Shift)도 된다.
- [ ] 글자를 바로 고칠 수 있다. 붙여넣으면 서식 없는 글자로 들어간다. 한글 조합 중에 단축키가 끼어들지 않는다.

**스타일**
- [ ] 글자색, 배경, 테두리, 둥글기, 투명도, 그림자를 바꿀 수 있다.

**추가**
- [ ] 텍스트와 도형을 추가할 수 있다.
- [ ] 이미지를 붙여넣기나 끌어다 놓기로 추가할 수 있다. 파일 안에 넣어지므로 저장한 뒤에도 보인다.

**정리**
- [ ] 복사, 복제, 삭제가 된다.
- [ ] 앞뒤 순서를 바꿀 수 있다.
- [ ] 정렬 가이드(옮길 때 맞춤선)가 나오고, 정렬·배분이 된다.

**모션**
- [ ] 요소마다 등장·강조·퇴장 모션과 단계를 지정할 수 있다. 결과는 data- 속성으로 저장된다.
- [ ] 지정한 모션을 바로 미리볼 수 있다.

**슬라이드**
- [ ] 슬라이드를 추가, 복제, 삭제(확인 창), 숨기기 할 수 있다.
- [ ] 끌어서 순서를 바꿀 수 있다.

**저장**
- [ ] 되돌리기 / 다시 하기가 된다.
- [ ] 파일로 저장한다. 크롬·엣지는 파일에 직접 저장하고, 다른 브라우저는 다운로드로 받는다. (손) 크롬의 저장 창은 실제 브라우저에서 확인한다.
- [ ] 저장한 파일에 수업 중 상태(선택 테두리, 단계 표시, 열린 퀴즈)가 남지 않는다. 저장한 파일을 다시 열어 이어서 고칠 수 있다.
- [ ] 자동 임시 저장이 되고, 다음에 열 때 복구할지 묻는다.
- [ ] 저장하지 않고 닫으려 하면 경고한다.

**점검**
- [ ] 자동 점검이 다음을 찾아 목록으로 보여 주고, 누르면 그 위치로 간다: 넘치는 글자, 빈 슬라이드, 깨진 그림, 24px보다 작은 글자, 무대 밖 요소, 모르는 data- 값.

## 6. 모션

data- 값은 [CLAUDE.md](../CLAUDE.md) 4장의 약속을 따른다. 모든 모션은 강도 4단계와 속도 배율에 따라 달라지고, "끄기"에서는 바로 끝 모습이 된다.

| 묶음 | 이름 → 값 |
| --- | --- |
| 전환 `data-transition` | 서서히 `fade` · 밀어내기 `push` · 덮기 `cover` · 확대 `zoom` · 뒤집기 `flip` · 쓸어내기 `wipe` · 원형 `circle` · 모프 `morph`(`data-morph` 이름이 같은 요소끼리 이어서 움직임) |
| 등장 `data-anim` | 페이드 `fade` · 튀어나오기 `pop` · 떨어지기 `drop` · 흐림→선명 `blur` · 단어씩 `words` · 글자씩 `letters` · 타자기 `typewriter` · 차례로 `data-stagger` |
| 강조 `data-emph` | 두근 `pulse` · 흔들기 `shake` · 빛나기 `glow` · 형광펜 `highlight` · 밑줄 `underline` · 동그라미 `circle` · 스포트라이트 `spotlight` |
| 퇴장 `data-exit` | 취소선 `strike` · 사라지기 `fade` · 줄어들기 `shrink` |
| 숫자·도식 | 숫자 올라가기 `data-count-to` · 막대 자라기 `data-grow` · 선 그리기 `data-draw` |
| 배경 움직임 `data-ambient` | 사진 천천히 확대 `kenburns` · 천천히 흐르기 `drift` |
| 상호작용 | 뒤집기 카드 `data-flip` · 가리개 `data-cover` · 퀴즈 `data-quiz` · 눌러서 크게 보기 `data-zoomable` · 핫스팟 `data-hotspot` |

- [ ] 위 표의 모든 값이 시범 덱 어딘가에 한 번 이상 쓰였고, 눌러 보면 동작한다.
- [ ] 상호작용 활동은 슬라이드에 들어올 때마다 처음 상태로 돌아간다.
- [ ] `?static&full`로 열면 모션 없이 모든 단계가 펼쳐진다(인쇄·캡처용).

## 7. 설정

- [ ] 모션 강도: 끄기 / 차분 / 기본 / 화려
- [ ] 모션 속도: 0.5배 ~ 2배
- [ ] 테마: 덱 테마 변수 묶음을 바꾼다. 도구 화면도 밝게/어둡게 바꿀 수 있다.
- [ ] 도구 위치를 바꿀 수 있다. 어느 위치에서도 슬라이드를 가리지 않는다.
- [ ] 효과음 켜기/끄기
- [ ] 기기에서 "동작 줄이기"가 켜져 있으면 "차분"으로 시작한다(`prefers-reduced-motion`을 흉내 내어 확인한다).
- [ ] 설정은 다음에 열 때도 그대로다.

## 8. 단축키

- [ ] 모든 기능을 버튼과 단축키 둘 다로 쓸 수 있다.
- [ ] `?` 키로 단축키 목록이 나온다. 목록은 엔진이 가진 실제 단축키 표에서 만들어서, 목록과 실제 동작이 어긋나지 않는다.
- [ ] 한글 입력 상태에서도 단축키가 동작한다(`e.code`).

## 9. 시범 덱과 확인

- [ ] 시범 슬라이드는 5장쯤 넣는다. 주제는 사용자에게 받는다(비어 있으면 묻는다).
- [ ] 5장 안에 전환·등장·강조·퇴장·숫자·도식·상호작용이 고루 들어간다.
- [ ] 다 만들면 브라우저로 열어 기능을 직접 눌러 보고, 보고는 세 가지로 나눈다.
  - 확인함: 어떻게 확인했는지 함께 쓴다.
  - 확인 못 함: 이유를 쓴다.
  - 알려진 문제
