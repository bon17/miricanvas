# 냉전과 제3 세계 — 수업 슬라이드 (움직이는 HTML)

중2 역사 「냉전의 성립과 해체, 제3 세계의 성장」 수업용 30장짜리 슬라이드.
미리캔버스로 잡은 디자인을 바탕으로, 글자는 HTML로 다시 써서 크게 키우고 애니메이션과 활동을 넣었다.

## 빌드

```bash
python3 slides/build.py
```

- `src/index.html`: 슬라이드 원본. 이미지는 `{{img:이름}}` 자리표시자로 들어 있다.
- `assets/*.jpg`: 교과서 사진·지도. 저작권 때문에 저장소에는 올리지 않는다(.gitignore).
- `assets/PretendardVariable.woff2`: 이 파일이 있고 `pip install fonttools brotli`가 되어 있으면, 쓰인 글자만 남긴 폰트를 결과 파일에 넣는다. 그러면 인터넷이 없어도 같은 글꼴로 보인다. 없으면 CDN을 쓴다.
- `dist/index.html`: 이미지와 폰트가 모두 들어간 단일 파일. 이 파일 하나만 열면 된다(저장소에는 올리지 않음).

## 조작법

| 키 | 동작 |
| --- | --- |
| → · Space · Enter · 화면 클릭 | 다음 단계 / 다음 슬라이드 |
| ← · 오른쪽 클릭 | 이전 단계 / 이전 슬라이드 |
| ↓ · ↑ | 단계를 건너뛰고 슬라이드 이동 |
| M | 슬라이드 목록 |
| F | 전체 화면 |
| ? | 도움말 |

주소 뒤에 `#12`를 붙이면 12번 슬라이드에서 시작한다. `?static&full`을 붙이면 애니메이션 없이 모든 단계가 펼쳐진 상태로 보인다(인쇄·캡처용).
