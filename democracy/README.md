# 민주주의와 인권의 확산 — 수업 슬라이드

중2 역사 Ⅶ-02 「민주주의와 인권의 확산」(교과서 228~233쪽) 45분 수업용 77장 HTML 슬라이드.

```
democracy/
├── index.html   ← 이 파일을 더블클릭해서 연다 (CSS·JS가 모두 들어 있음)
├── images/      ← 사진을 넣는 곳 (목록은 images/README.txt)
└── fonts/       ← Black Han Sans, IBM Plex Sans KR (SIL OFL, 슬라이드용으로 줄인 woff2)
```

- 인터넷 없이 `file://`로 열어도 된다. 크롬 · 엣지 · 웨일.
- 폴더째 USB나 교실 PC로 옮긴다. `index.html`만 따로 옮기면 사진과 글꼴이 빠진다.

## 조작

| 입력 | 동작 |
| --- | --- |
| → ↓ Space PageDown Enter | 다음 장 |
| ← ↑ PageUp Backspace | 이전 장 |
| Home / End | 처음 / 마지막 장 |
| 숫자 입력 후 Enter | 그 번호의 장으로 (예: `36` Enter). 1.5초 안에 Enter를 눌러야 하고, 잘못 누른 숫자는 Backspace로 지운다 |
| F | 전체 화면 |
| S | 선택 장(18, 25, 37, 46, 49, 69) 건너뛰기. 켜지면 오른쪽 아래에 "선택 장 건너뜀" |
| N | 교사 메모 |
| O | 전체 장 목록. 누르면 이동, Esc로 닫기 |
| M | 움직임 끄기·켜기. 끄면 오른쪽 아래에 "움직임 끔". 컴퓨터에서 '애니메이션 줄이기'를 켜 두었으면 처음부터 꺼져 있다 |
| 클릭 | 화면 오른쪽 2/3는 다음, 왼쪽 1/3은 이전 (61번 비교 사진 위는 제외) |
| 스와이프 | 좌우로 장 이동 |

주소 끝의 `#36`이 지금 장 번호다. 새로고침해도 같은 장이 열린다.

## 움직임

- 장 전환: 다음 장이 화면을 닦아 내듯 들어오고, 이야기(평등·노동·생존·정리)가 바뀔 때는 그 이야기 색의 띠가 지나간다.
- 피켓은 아래에서 들려 올라와 흔들리고, 뒤로 군중 피켓이 함께 올라온다.
- 큰 연도는 숫자가 올라가며 멈추고(예: 1904 → 1964), 사진은 닦아 내듯 나타난 뒤 천천히 줌된다.
- 아이콘은 선이 그려지고, 09번은 형광펜이 칠해지고, 33번은 날짜가 차례로 뜬 뒤 5월 1일 동그라미가 돈다.
- 큰 문장은 단어가 하나씩 또렷해지고, 61번은 손잡이가 한 번 좌우로 움직여 끌 수 있다는 것을 보여 준다.
- 66→67번은 원이 커진다. 76번 마지막 화살표는 계속 흐른다.

## 교사가 채울 것

1. **사진 넣기**: `images/README.txt` 목록의 파일명 그대로 `images/` 폴더에 넣는다. 교과서 사진 19장과, 교과서에 없어 따로 구할 사진 17장(검색어 포함)이 나뉘어 있다. 넣지 않은 사진은 점선 자리표시로 보인다.
2. **연설문 (08·09번)**: 교과서 228쪽 마틴 루서 킹 연설문 발췌를 08번에 넣어 두었다(교과서 PDF에서 그대로 옮김). 바꾸려면 `index.html`에서 `✍️` 주석을 찾아 바로 아래 글을 고친다. 강조할 구절은 `<mark>…</mark>`로 감싼다. 08번에서는 강조 없이, 09번에서만 형광펜으로 보인다. 글을 지우면 화면에 "여기에 교과서 228쪽 마틴 루서 킹 연설문 발췌를 붙여 넣으세요."가 나온다.
3. **27번 확대 위치**: 사진을 넣은 뒤 27번의 `data-zoom`(배율), `data-focus`(위치) 값을 피켓이 보이게 조정한다.
4. **사진 잘림 위치**: 필요하면 각 사진의 `data-focus="가로% 세로%"` 값을 조정한다. 잘리지 않게 전부 보이려면 `data-fit="contain"`.

## 문구 고치기

`index.html`을 메모장이나 VS Code로 연다. 장마다 `<!-- 05. 핵심 질문 -->`처럼 번호와 제목 주석이 있다. 그 아래 `<section>` 안의 글자를 고치고 저장한 뒤 브라우저에서 새로고침한다.

- `<br>`은 줄바꿈이다.
- `<aside class="notes">` 안은 교사 메모(N 키)다.
- 정리표(31·47·70·71번)는 "정리표 데이터", 패턴(73~76번)은 "패턴 데이터" 주석 아래 한 곳에서만 고친다.
- 글꼴 파일에는 슬라이드에 쓰인 글자와 자주 쓰는 한글 2,350자가 들어 있다. 아주 드문 글자를 새로 쓰면 그 글자만 맑은 고딕으로 보일 수 있다. `tools/democracy/subset_fonts.py`로 글꼴을 다시 만들면 된다.

## 파일 하나로 만들기

글꼴과 사진을 HTML 안에 모두 넣어, 파일 하나만 내려받아 열 수 있게 만든다.

```bash
python3 -I tools/democracy/build_single.py "democracy/dist/민주주의와 인권의 확산.html" 사진폴더
```

- 사진 폴더를 생략하면 `democracy/images`를 쓴다. 폴더에 없는 사진은 자리표시로 보이고, 결과 파일 옆에 `images/` 폴더를 두고 그 사진을 넣으면 그대로 보인다.
- 교과서 사진이 들어간 결과 파일(`democracy/dist/`)은 저장소에 올리지 않는다.
- 60·61번 아랄해 사진 틀은 1989 사진의 가로세로 비율에 맞춰 너비가 바뀐다(최대 900px).

## 검수 (개발용)

```bash
node tools/democracy/check.js democracy/index.html 스크린샷폴더 1920x1080
```

```bash
node tools/democracy/interact.js
```

- `check.js`: 77장 번호, 글꼴, 콘솔 오류, 장마다 무대 밖 글자 · 넘침 · 32px 미만 글자 · 아래 여백 침범, 스크린샷.
- `interact.js`: 모든 키, 숫자 이동, S 모드, 메모, 목록, 클릭 · 스와이프, 61번 슬라이더(마우스 · 터치), 66→67 원, 움직임 줄이기 설정 등.
- 사진이 없으면 브라우저가 "Failed to load resource"를 콘솔에 남긴다. 사진을 모두 넣으면 사라진다.
