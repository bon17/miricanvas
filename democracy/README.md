# 민주주의와 인권의 확산 — 수업 슬라이드

중2 역사 Ⅶ-02 「민주주의와 인권의 확산」(교과서 228~233쪽) 45분 수업용 78장 HTML 슬라이드.

```
democracy/
├── index.html   ← 이 파일을 더블클릭해서 연다 (CSS·JS가 모두 들어 있음)
├── images/      ← 사진을 넣는 곳 (목록은 images/README.txt)
└── fonts/       ← Black Han Sans, IBM Plex Sans KR (SIL OFL, 슬라이드용으로 줄인 woff2)
```

- 인터넷 없이 `file://`로 열어도 된다. 크롬 · 엣지 · 웨일.
- 폴더째 USB나 교실 PC로 옮긴다. `index.html`만 따로 옮기면 사진과 글꼴이 빠진다.

## 조작

왼쪽 아래의 둥근 단추를 누르면 도구 여섯 묶음이 부채꼴로 펼쳐집니다: 이동 · 필기 · 발표 도구 · 칠판 · 편집 · 설정. 단추는 끌어서 네 구석 어디로든 옮길 수 있습니다. 모든 기능은 단축키로도 쓸 수 있고, **? 키**를 누르면 목록이 나옵니다.

| 입력 | 동작 |
| --- | --- |
| → ↓ Space PageDown Enter / ← ↑ PageUp Backspace | 다음 / 이전 (그 장에 남은 단계가 있으면 단계부터) |
| Home / End, 숫자 → Enter | 처음 / 끝, 그 번호의 장 (1.5초 안에 Enter) |
| G / O | 목차 / 썸네일 목록 |
| S | 선택 장(19, 26, 38, 47, 50, 70) 건너뛰기 켜기·끄기 |

- 한글 자판 상태에서도 글자 키가 그대로 동작합니다.
- 주소 끝의 `#36`이 지금 장 번호입니다. 새로고침해도 같은 장이 열립니다.
- **전체 화면**에서는 슬라이드와 쪽 번호만 보입니다. 가장자리에 마우스를 대거나 탭하면 도구 단추가 잠깐 나타납니다. 마우스가 멈추면 커서도 숨습니다.
- **필기**는 장마다 이 컴퓨터의 브라우저에 저장됩니다. 창 크기가 바뀌어도 자리가 그대로입니다.
- **단계(답 보이기)**: 14 · 20 · 21 · 37번은 다음 키를 한 번 더 누르면 같은 장에서 답이 나타납니다. 오른쪽 아래에 노란 "▸ 답"이 보이면 아직 보일 답이 남았다는 뜻입니다.

## 움직임

- 장 전환: 다음 장이 화면을 닦아 내듯 들어오고, 이야기(평등·노동·생존·정리)가 바뀔 때는 그 이야기 색의 띠가 지나간다.
- 피켓은 아래에서 들려 올라와 흔들리고, 뒤로 군중 피켓이 함께 올라온다.
- 큰 연도는 숫자가 올라가며 멈추고(예: 1904 → 1964), 사진은 닦아 내듯 나타난 뒤 천천히 줌된다.
- 아이콘은 선이 그려지고, 09번은 형광펜이 칠해지고, 33번은 날짜가 차례로 뜬 뒤 5월 1일 동그라미가 돈다.
- 큰 문장은 단어가 하나씩 또렷해지고, 61번은 손잡이가 한 번 좌우로 움직여 끌 수 있다는 것을 보여 준다.
- 67→68번은 원이 커진다. 77번 마지막 화살표는 계속 흐른다.

## 교사가 채울 것

1. **사진 넣기**: `images/README.txt` 목록의 파일명 그대로 `images/` 폴더에 넣는다. 교과서 사진 19장과, 교과서에 없어 따로 구할 사진 17장(검색어 포함)이 나뉘어 있다. 넣지 않은 사진은 점선 자리표시로 보인다.
2. **연설문 (08·09번)**: 교과서 228쪽 마틴 루서 킹 연설문 발췌를 08번에 넣어 두었다(교과서 PDF에서 그대로 옮김). 바꾸려면 `index.html`에서 `✍️` 주석을 찾아 바로 아래 글을 고친다. 강조할 구절은 `<mark>…</mark>`로 감싼다. 08번에서는 강조 없이, 09번에서만 형광펜으로 보인다. 글을 지우면 화면에 "여기에 교과서 228쪽 마틴 루서 킹 연설문 발췌를 붙여 넣으세요."가 나온다.
3. **28번 확대 위치**: 사진을 넣은 뒤 28번의 `data-zoom`(배율), `data-focus`(위치) 값을 피켓이 보이게 조정한다.
4. **사진 잘림 위치**: 필요하면 각 사진의 `data-focus="가로% 세로%"` 값을 조정한다. 잘리지 않게 전부 보이려면 `data-fit="contain"`.

## 문구 고치기

**화면에서 고치기 (편집 모드, E)**

- **선택과 이동**: 요소를 누르면 고릅니다. 끌면 옮기고, 손잡이로 크기를 바꾸거나 돌립니다. 한 번 더 누르면 안쪽 요소를 고르고, ↑ 단추는 바깥 요소를 고릅니다.
- **글자**: 두 번 누르면 글자를 고칩니다. Esc로 끝냅니다.
- **꾸미기와 모션**: 고른 요소 위의 알약 막대에서 바꿉니다.
  - 꾸미기: 글자색 · 배경 · 테두리 · 둥글기 · 투명도 · 그림자 · 글자 크기
  - 모션: 등장 · 강조 · 퇴장 · 숫자 · 상호작용, 미리보기
  - 정렬과 순서
- **추가와 장 관리**: 구석 단추를 누르면 펼쳐집니다.
  - 추가: 글상자 · 도형 · 그림 · 핫스팟
  - 장: 새 장 · 복제 · 숨기기 · 지우기 · 전환 효과 · 배경 움직임
  - 점검: 넘치는 글자 · 빈 장 · 깨진 그림
- **장 목록**: 아래에 깔리며, 끌어서 순서를 바꿉니다.
- **그림**: 끌어다 놓거나 붙여 넣으면 들어갑니다. 사진 위에 놓으면 그 사진이 바뀝니다.
- **되돌리기**: Ctrl+Z / Ctrl+Y.
- **정리표와 패턴**: 정리표(32·48·71·72번)와 패턴(74~77번) 칸은 글자만 고칠 수 있고, 같은 표를 쓰는 다른 장에도 바로 반영됩니다. 09번 연설문은 08번에서 고칩니다.
- **저장**: Ctrl+S(또는 아래 띠의 '저장')를 누릅니다.
  - 크롬 · 엣지 · 웨일은 저장 위치를 물어봅니다. 처음 연 파일을 골라 덮어쓸 수 있습니다.
  - 그 밖의 브라우저는 다운로드 폴더에 새 파일로 받습니다.
- **임시 저장과 복구**: 편집하는 동안 자동으로 임시 저장합니다. 파일로 저장하지 않고 닫았다가 다시 열면 되살릴지 묻습니다.

**파일에서 고치기**: `index.html`을 메모장이나 VS Code로 엽니다.

- 장마다 `<!-- 05. 핵심 질문 -->`처럼 번호와 제목 주석이 있습니다. 그 아래 `<section>` 안의 글자를 고칩니다.
- `<br>`은 줄바꿈입니다.
- `<aside class="notes">` 안은 교사 메모입니다.
- 정리표 · 패턴은 "정리표 데이터", "패턴 데이터" 주석 아래 한 곳에서만 고칩니다.
- `<style id="se-css">`, `<script id="se-js">` 칸은 엔진입니다. 손으로 고치지 않고 `python3 -I tools/engine/inject.py democracy/index.html`로 바꿉니다(`engine/README.md`).
- 글꼴 파일에는 슬라이드에 쓰인 글자와 자주 쓰는 한글 2,350자가 들어 있습니다. 아주 드문 글자는 맑은 고딕으로 보일 수 있습니다. `tools/democracy/subset_fonts.py`로 글꼴을 다시 만듭니다.

## 파일 하나로 만들기

글꼴과 사진을 HTML 안에 모두 넣어, 파일 하나만 내려받아 열 수 있게 만든다.

```bash
python3 -I tools/democracy/build_single.py "democracy/dist/민주주의와 인권의 확산.html" 사진폴더
```

- 사진 폴더를 생략하면 `democracy/images`를 쓴다. 폴더에 없는 사진은 자리표시로 보이고, 결과 파일 옆에 `images/` 폴더를 두고 그 사진을 넣으면 그대로 보인다.
- 교과서 사진이 들어간 결과 파일(`democracy/dist/`)은 저장소에 올리지 않는다.
- 사진 틀은 사진의 가로세로 비율에 맞춰 크기가 바뀌어 사진이 잘리지 않는다(사진 장·사진과 질문 장·오른쪽 사진 단). 콜라주·카드·패턴의 작은 사진만 틀에 맞춰 잘린다.
- 61·62번 아랄해 사진 틀은 1989 사진의 가로세로 비율에 맞춰 너비가 바뀐다(최대 900px).

```bash

```

- `interact.js`: 이 덱에서 확인하는 것.
  - 이동: 모든 키, 숫자 이동, 단계, 선택 장 건너뛰기, 메모, 썸네일, 클릭 · 스와이프
  - 이 덱의 장치: 62번 슬라이더(마우스 · 터치), 67→68 원, 이야기 전환 띠, 모션 강도, 전체 화면
  - 편집 모드: 고치고 저장한 파일 다시 열기
- `tools/engine/test.js`: 엔진 기능 전체(견본 덱).
- 사진이 없으면 브라우저가 "Failed to load resource"를 콘솔에 남긴다. 사진을 모두 넣으면 사라진다.
